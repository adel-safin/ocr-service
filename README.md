# OCR Document Processing Service

Сервис для обработки документов с использованием OCR (PaddleOCR CPU, lang=ru, в Docker), автоматической коррекции ошибок распознавания и машинного обучения.

## Основные возможности

- **OCR распознавание** на PaddleOCR CPU (Docker, lang=ru, без GPU)
- **Веб-интерфейс** для загрузки и обработки документов
- **Выделение областей** с повышенным DPI (900) для критических участков
- **Автокоррекция** ошибок OCR (контекстная замена 0→о/О, 8→в/В)
- **Валидация полей** (ИНН, СНИЛС, ОГРН, даты, номера документов)
- **Классификация документов** (ML модель)
- **Активное обучение** на основе обратной связи
- **Многостраничная обработка** PDF документов

## Архитектура

Система реализована в три фазы:

### Фаза 1: Базовый OCR + правила

- **OCR Engine**: PaddleOCR CPU (Docker, lang=ru)
- **Автокоррекция**: Правила (0/8 в словах), латиница→кириллица в смешанных словах (фамилии), база замен `data/corrections.json`
- **Валидация**: Проверка критических полей (ИНН, СНИЛС, ОГРН и др.)
- **Качество**: Детекция проблемных областей (рукописный текст, наложения)
- **Многостраничность**: Постраничная обработка PDF
- **Улучшение качества**: см. [OCR_IMPROVEMENTS.md](../OCR_IMPROVEMENTS.md) — датасет, скрипт извлечения пар, Фазы 2–3

### Фаза 2: Машинное обучение

- **Классификатор документов**: CNN (ResNet18) для определения типа документа
- **Исправление опечаток**: Transformer модель (RuT5) - опционально
- **ML проверка качества**: Оценка качества изображения и распознавания
- **Обучение**: Скрипты для обучения на датасете

### Фаза 3: Активное обучение

- **Feedback loop**: Сбор обратной связи от пользователей
- **Автообновление**: Автоматическое обновление базы исправлений
- **Анализ паттернов**: Выявление частых ошибок
- **Адаптация**: Подстройка под новые типы документов

## Установка

### Требования

### Локальная установка

1. Создайте виртуальное окружение:

```bash
cd app
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# или
venv\Scripts\activate  # Windows
```

2. Установите Python зависимости:

```bash
pip install -r requirements.txt
```

**OCR (PaddleOCR CPU)**: распознавание через HTTP в Docker (lang=ru, без GPU). Перед запуском приложения поднимите сервер (см. [PADDLEOCR_DOCKER.md](../PADDLEOCR_DOCKER.md)):

```bash
./scripts/start_paddleocr_server.sh
```

### Docker установка

```bash
cd app
docker-compose up -d
```

## Использование

### Запуск сервиса

```bash
cd app
python run.py
```

Или через uvicorn:

```bash
cd app
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

Сервис будет доступен по адресу:

- **API**: http://localhost:8000
- **Веб-интерфейс**: http://localhost:8000
- **Документация API**: http://localhost:8000/docs

### Веб-интерфейс

1. Откройте http://localhost:8000 в браузере
2. Загрузите документ (PDF, JPG, PNG, BMP)
3. При необходимости выберите тип документа
4. Укажите обязательные поля (через запятую)
5. **Выделите критические области** на предпросмотре (опционально)
   - Выделенные области обрабатываются с DPI 900 для лучшего качества
6. Нажмите "Обработать документ"
7. Просмотрите результаты:
   - Предупреждения о качестве
   - Выделенные области (DPI 900)
   - Полный распознанный текст

### API Endpoints

#### 1. Обработка одного документа

```bash
curl -X POST "http://localhost:8000/api/v1/process" \
  -F "file=@document.pdf" \
  -F "template=act_aosr" \
  -F "required_fields=ogrn,inn,date" \
  -F "selected_areas=[{\"x1\":100,\"y1\":200,\"x2\":500,\"y2\":300}]"
```

**Параметры:**

- `file` (обязательно): Файл для обработки
- `template` (опционально): Тип документа
- `required_fields` (опционально): Список обязательных полей через запятую
- `selected_areas` (опционально): JSON массив с координатами выделенных областей `[{"x1": int, "y1": int, "x2": int, "y2": int}]`

#### 2. Пакетная обработка

```bash
curl -X POST "http://localhost:8000/api/v1/batch_process" \
  -F "files=@doc1.pdf" \
  -F "files=@doc2.pdf" \
  -F "template=act_aosr"
```

#### 3. Подтверждение исправления

```bash
curl -X POST "http://localhost:8000/api/v1/confirm_correction" \
  -H "Content-Type: application/json" \
  -d '{
    "original": "Маркуталь",
    "corrected": "Мариуполь",
    "add_to_db": true
  }'
```

#### 4. Получение базы исправлений

```bash
curl "http://localhost:8000/api/v1/corrections_db"
```

#### 5. Проверка здоровья

```bash
curl "http://localhost:8000/api/v1/health"
```

## Поддерживаемые форматы

- **PDF** (многостраничные, постраничная обработка)
- **JPG/JPEG**
- **PNG**
- **BMP**

## Поддерживаемые поля

Система автоматически распознает и валидирует:

- **ОГРН** (13 или 15 цифр)
- **ИНН** (10 или 12 цифр)
- **КПП** (9 цифр)
- **СНИЛС** (формат XXX-XXX-XXX XX)
- **Дата** (различные форматы)
- **Номер сертификата ЕАЭС**
- **Телефон** (российские форматы)
- **Email**
- **Номера документов** (с символом №)
- **Фамилии** (русские)

## Особенности

### Выделение областей с повышенным DPI

При выделении области на предпросмотре:

- Область обрабатывается с **DPI 900** (вместо стандартного 300)
- Применяется адаптивный препроцессинг
- Результаты отображаются отдельно в блоке "Выделенные области"

### Контекстная автокоррекция

Система автоматически исправляет частые ошибки OCR:

- `0` → `о` (в русских словах, с учетом регистра)
- `8` → `в` (в русских словах, с учетом регистра)
- Сохраняет числа в датах и номерах (например, "2023", "8 марта")

### Многостраничная обработка

PDF документы обрабатываются постранично:

- Каждая страница обрабатывается отдельно
- Результаты сохраняются с указанием номера страницы
- Текст объединяется с разделителями

### Проверка качества

Система автоматически определяет:

- Низкое качество исходного изображения
- Области с возможным рукописным текстом
- Текст с наложениями/штампами
- Точные координаты проблемных областей

## 🛠️ Разработка

### Добавление нового типа поля

Отредактируйте `core/validators.py` и добавьте новый паттерн в `FieldValidator.PATTERNS`:

```python
PATTERNS = {
    'new_field': re.compile(r'...'),
    # ...
}
```

### Добавление автозамены

1. **Через API**:

```bash
curl -X POST "http://localhost:8000/api/v1/confirm_correction" \
  -H "Content-Type: application/json" \
  -d '{"original": "ошибка", "corrected": "правильно", "add_to_db": true}'
```

2. **Вручную**: Отредактируйте `data/corrections.json`

### Обучение ML моделей

1. Подготовьте датасет
2. Запустите обучение:

```bash
cd app
python scripts/train_all_ml.py
```

3. Модели сохранятся в `app/models/checkpoints/`

### Активное обучение

Система автоматически собирает данные при обработке. Для анализа:

```bash
cd app
python scripts/analyze_feedback.py
```

## Конфигурация

Настройки находятся в `config/settings.py`:

- `OCR_DPI`: Базовый DPI для OCR (по умолчанию 300)
- `SELECTED_AREA_DPI`: DPI для выделенных областей (по умолчанию 900)
- `USE_ML`: Использовать ML компоненты (по умолчанию True)
- `USE_ACTIVE_LEARNING`: Использовать активное обучение (по умолчанию True)

## Решение проблем

### PaddleOCR / OCR не работает

1. Запустите Docker-сервер: `./scripts/start_paddleocr_server.sh` (см. [PADDLEOCR_DOCKER.md](../PADDLEOCR_DOCKER.md)).
2. Проверьте: `curl -s http://127.0.0.1:8080/health` и `PADDLEOCR_SERVER_URL` в настройках.
3. В приложении нужен только `requests` (уже в requirements.txt).

### Ошибки при обработке PDF

Убедитесь, что установлен `poppler`:

```bash
# macOS
brew install poppler
```

### Плохое качество распознавания

1. Используйте **выделение областей** с DPI 900 для критических участков
2. Проверьте качество исходного изображения
